# MORPHO

Полная версия сайта с видеофонами, вертикальными свайпами и открывающейся 3D-банкой.

Для запуска распакуйте архив и запустите HTTP-сервер в этой папке. Например: `python -m http.server 8000`, затем откройте http://localhost:8000. Для 3D-анимации требуется HTTP-сервер: открытие через file:// ограничивает загрузку текстур браузером.

Опубликованный сайт: https://morpho-click-journey-dimon.ribbedebony.chatgpt.site/
